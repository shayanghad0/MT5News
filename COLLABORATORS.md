## How to Contribute

1. Fork the repository.
2. Create a feature branch (`git checkout -b feat/your-feature`).
3. Commit changes with clear messages.
4. Open a Pull Request referencing any related issues.

## Coding Standards

- Follow PEP 8 for Python code.
- Use conventional commits (`feat:`, `fix:`, `docs:`, `refactor:`, etc.).
- Add tests for new logic where applicable.
- Update `readme.md` if behavior changes.

## Attribution

Contributions are acknowledged here and in commit history. Co-authored-by trailers are added for multi-author commits.
